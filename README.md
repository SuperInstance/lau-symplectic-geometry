# lau-symplectic-geometry

**Symplectic geometry as the bridge between contact geometry, optimal control, and Hamiltonian mechanics.**

A Rust library implementing symplectic manifolds, Hamiltonian mechanics, symplectic integrators, Poisson brackets, cotangent bundles, Darboux coordinates, Liouville's theorem, and Poincaré recurrence — the mathematical foundation for conservative dynamical systems and robotics trajectory planning.

## What This Does

Symplectic geometry studies manifolds equipped with a **non-degenerate closed 2-form** ω. This structure arises naturally in:

- **Hamiltonian mechanics**: Phase space (positions + momenta) is a symplectic manifold
- **Optimal control**: The Pontryagin maximum principle lives on cotangent bundles
- **Robotics**: Trajectory planning for conservative systems (satellites, pendulums, articulated bodies)

This crate provides:

- **Symplectic forms** and verification of non-degeneracy
- **Symplectic matrices** in Sp(2n) — the linear symplectic group
- **Hamiltonian systems** with prebuilt examples (harmonic oscillator, pendulum, Kepler problem)
- **Symplectic integrators** that preserve the symplectic structure (Euler, Störmer-Verlet)
- **Poisson brackets** with verification of skew-symmetry, bilinearity, Jacobi identity, and Leibniz rule
- **Cotangent bundles** T*M as canonical symplectic manifolds
- **Darboux coordinates** — local coordinates where ω = Σ dxᵢ ∧ dpᵢ
- **Liouville's theorem** — phase space volume preservation verification
- **Poincaré recurrence** — return-time detection in bounded phase space regions

---

## Key Idea

A **symplectic form** ω on a 2n-dimensional manifold is a closed, non-degenerate 2-form. "Closed" (dω = 0) means it's locally constant; "non-degenerate" means ω(u, v) = 0 for all v implies u = 0. Together, these mean ω pairs up position and momentum coordinates.

Hamiltonian flows generated by X_H = J∇H **preserve** ω. This has profound consequences:

1. **Liouville's theorem**: Phase space volume is conserved
2. **Energy conservation**: dH/dt = 0 along the flow
3. **Poincaré recurrence**: In bounded regions, trajectories come arbitrarily close to their starting point

A **symplectic integrator** is a numerical method that preserves this structure. Standard Runge-Kutta methods do not — they introduce artificial energy drift. Symplectic Euler and Störmer-Verlet do, making them ideal for long-time simulations.

## Quick Start

```rust
use lau_symplectic_geometry::{
    SymplecticForm, HamiltonianSystem, SymplecticEuler, StormerVerlet,
    PoissonBracket, LiouvilleTheorem,
};

// --- Symplectic form on R^2 (canonical: ω = dp ∧ dq) ---
let omega = SymplecticForm::canonical(1); // 1 degree of freedom → 2D phase space
let u = nalgebra::DVector::from_vec(vec![1.0, 0.0]);
let v = nalgebra::DVector::from_vec(vec![0.0, 1.0]);
assert!(omega.apply(&u, &v).abs() > 0.0); // Non-degenerate

// --- Hamiltonian system: simple pendulum ---
let pendulum = HamiltonianSystem::pendulum();

// Integrate with Störmer-Verlet (symplectic!)
let verlet = StormerVerlet::new(0.01);
let trajectory = verlet.integrate(
    &pendulum,
    &nalgebra::DVector::from_vec(vec![1.0]),  // initial position
    &nalgebra::DVector::from_vec(vec![0.0]),  // initial momentum
    1000,  // steps
);

// Check energy conservation (should be tiny drift)
let drift = pendulum.energy_drift(&trajectory);
assert!(drift.abs() < 1e-6);

// --- Poisson brackets ---
let bracket = PoissonBracket::new(1);
// {q, p} = 1 (canonical bracket)
let grad_q = nalgebra::DVector::from_vec(vec![1.0, 0.0]);
let grad_p = nalgebra::DVector::from_vec(vec![0.0, 1.0]);
let pb = bracket.bracket(&grad_q, &grad_p);
assert!((pb - 1.0).abs() < 1e-10);

// --- Liouville volume preservation ---
let jacobian = /* flow Jacobian from integration */;
assert!(LiouvilleTheorem::verify_volume_preservation(&jacobian));
```

## The Math

### Symplectic Forms

A **symplectic form** ω on a 2n-dimensional manifold M is a differential 2-form that is:

1. **Closed**: dω = 0 (locally, ω = dθ for some 1-form θ)
2. **Non-degenerate**: ω(u, v) = 0 ∀v ⟹ u = 0

On R²ⁿ with coordinates (q₁, …, qₙ, p₁, …, pₙ), the canonical symplectic form is:

> ω = Σᵢ dpᵢ ∧ dqᵢ

In matrix form: ω = [0, I; −I, 0] (the block matrix J).

### The Symplectic Group Sp(2n)

A matrix M ∈ Sp(2n) satisfies M^T J M = J. These are the **linear symplectomorphisms** — linear maps preserving ω. Properties:

- det(M) = 1 always (Liouville's theorem at the linear level)
- M⁻¹ = −J M^T J (explicit inverse formula)
- Sp(2n) is a Lie group of dimension n(2n + 1)

### Hamiltonian Mechanics

Given a function H: M → R (the Hamiltonian), the **Hamiltonian vector field** X_H is defined by:

> ω(X_H, ·) = dH

In coordinates: X_H = (∂H/∂p, −∂H/∂q). The flow of X_H preserves ω and H (energy conservation).

### Symplectic Integrators

Standard numerical integrators (Euler, RK4) do not preserve the symplectic form. Over long times, this causes **energy drift** — the simulation slowly gains or loses energy.

**Symplectic integrators** preserve ω exactly (up to floating point), giving bounded energy error over arbitrarily long integration times:

- **Symplectic Euler**: 1st-order. For separable H = T(p) + V(q), alternates exact p-step and exact q-step.
- **Störmer-Verlet**: 2nd-order. The workhorse of molecular dynamics and celestial mechanics. Time-reversible and symplectic.

### Poisson Brackets

The **Poisson bracket** {f, g} = ω(X_f, X_g) = (∇f)^T J (∇g) satisfies:

- Skew-symmetry: {f, g} = −{g, f}
- Bilinearity: linear in each argument
- Jacobi identity: {{f,g},h} + {{g,h},f} + {{h,f},g} = 0
- Leibniz rule: {f, gh} = g{f,h} + {f,g}h

These make C^∞(M) a **Poisson algebra**, and the Jacobi identity is equivalent to the closeness of ω.

### Darboux's Theorem

**Darboux's theorem**: Every symplectic form locally looks like the canonical one. That is, for any point in M, there exist local coordinates (q, p) where ω = Σ dqᵢ ∧ dpᵢ. This is strikingly different from Riemannian geometry, where curvature is a local invariant — symplectic manifolds have **no local invariants**.

### Liouville's Theorem

Hamiltonian flow preserves the **Liouville measure** ω^n = ω ∧ … ∧ ω (n times). Equivalently, |det(Jacobian)| = 1 at every time. Phase space volume is conserved — you can't compress it.

### Poincaré Recurrence

If the phase space available to the system has finite volume (e.g., bounded energy surface), then almost every trajectory returns arbitrarily close to its starting point. The **Poincaré recurrence time** depends on the volume and the tolerance — for macroscopic systems it exceeds the age of the universe, but for simple systems it's directly observable.
